MODE 3 · ACTUATOR ENGINEERING

Worst-case static torque per axis

Sweeps the shoulder (J2) and elbow (J3) through their full limits with the wrist pitched, finds the highest gravity holding torque for each axis, and compares it with the continuous rating of the selected reducer and the motor reflected through the ratio. The single nominal-posture check on the Engineering checks page can pass while a stretched-out arm does not.

The dynamic analysis then drives the arm along the saved task path and reports peak and RMS torque and motor speed per axis against the peak and continuous ratings.

Source meshes are converted only when they form valid closed solids. Unknown or open .robot geometry is rejected rather than guessed.

STL → STEP FOR MANUFACTURING CAD

Convert an STL part to a STEP solid

Feature CAD rebuilds the part with ordinary CAD operations — extruded outlines, revolves about the axes the part turns on, and bores — so every face is a plane, cylinder, cone, sphere or torus. The deviation from the STL is measured and reported.

The STL carries the external form only; wall thickness, internal features and tolerances are not inferred.

Benchmark scope

This release extracts geometry and header metadata from supported RoboDK files and exports a reference STEP package. It does not yet create a joined ABB/Yaskawa-versus-Raed automated comparison or certify manufacturer data.
